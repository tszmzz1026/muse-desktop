Muse.ai 非官方 Windows 桌面客户端首个公开版本。

## 下载

- **推荐安装版**：`Muse-Desktop-1.0.0-Setup.exe`，双击安装，按需联网安装 Microsoft WebView2 Runtime。
- **便携版**：`Muse-Desktop-1.0.0-win-x64.zip`，全部解压后运行 `Muse.exe`，同目录 DLL 需要保留。
- **文件校验**：`SHA256SUMS.txt`。

支持 Windows 10 2004 及以上版本、Windows 11，64 位系统。

## 功能

- WebView2 原生桌面客户端，只有一层标题栏，网页铺满窗口。
- 关闭进入系统托盘，恢复时保留页面和未发送的输入。
- 再次启动恢复同一个窗口；支持托盘右键彻底退出。
- 自动记忆窗口大小、位置和最大化状态。
- 登录弹页在同一个主窗口内显示。

首次使用请在软件内登录自己的 Muse 账户。客户端与 Edge 浏览器的登录数据独立，不包含发布者的账号或聊天记录。网站功能需要联网。
