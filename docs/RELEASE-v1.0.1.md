修复电脑重启后需要重新登录的问题。

- Muse 的会话 Cookie 使用 Windows 当前用户的加密保护保存在本机，启动时恢复。
- 登录状态定期保存，并在正常退出前完成保存，避免只在程序关闭时保存。
- 保留 Cookie 的 Secure、HttpOnly、SameSite、域名和路径属性，不修改持久 Cookie 的有效期。
- 主动退出登录后清除保存记录；损坏记录不会阻止软件打开。
- 增加正常重启、非正常退出、加密保存和主动注销的自动检查。

**升级后请先登录一次，建立新的会话记录。** 网站主动过期或撤销的登录仍需重新验证。

推荐下载 `Muse-Desktop-1.0.1-Setup.exe`；便携版请全部解压后运行 `Muse.exe`。支持 Windows 10 2004 及以上版本、Windows 11，64 位系统。
